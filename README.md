# Ai-aircraft-engine-fault-detection

AI-based aircraft engine fault detection and Remaining Useful Life (RUL) prediction using the NASA C-MAPSS dataset.

## Status
Work in progress.

## Goal
Detect engine degradation early, predict RUL, and turn predictions into maintenance decisions.

## Dataset
NASA C-MAPSS (simulated turbofan engine degradation data), FD001 subset to start.

## Planned Methods
- Baseline: Random Forest
- Deep learning: LSTM
- Explainability: SHAP
- Anomaly detection

## Limitations
Dataset is simulated, not real engine data.
